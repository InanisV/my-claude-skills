# User Stories 用户故事
## US1: 作为运营，想通过设置初始默认Tab来提升曝光及业务量
### US1-R1: 优化初始默认为合约
#### 前端说明
**Web/H5（涨幅榜、新币榜）**
1. web端涨幅榜、新币榜初始默认选中为 合约涨幅榜、合约新币榜；
2. 榜单其他逻辑不变；其他榜单逻辑也不变；
3. 兜底：如果后端获取合约涨幅榜/跌幅榜、合约新币榜失败，默认现货涨幅榜、现货新币榜。

**APP（热门榜、涨幅榜）**
1. APP端热门榜、涨幅榜初始默认Tab为 合约；
2. 榜单其他逻辑不变；其他榜单逻辑也不变；
3. 兜底：如果后端获取合约涨幅榜、热门榜失败，默认Tab为现货。

#### 兜底逻辑：不涉及，省略。
