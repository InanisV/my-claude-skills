# Check: 埋点平台拆分清晰度

## 检查对象
当需求同时涉及多个端（Web 与 App，或多个客户端）时，PRD 的埋点诉求是否说明清楚每条埋点落在哪个/哪些端。

## 判断标准
- 通过：埋点诉求明确了平台归属——要么逐条标注了 Web / App，要么有一句统一说明「以下埋点 Web 与 App 均需实现」之类，使后续可按端拆分埋点表。
- 不通过：需求明确同时做 Web 和 App（或多端），但埋点诉求完全没有区分平台，也没有任何「双端都要」的统一说明，导致无法判断每条埋点该在哪个端落地。

## 豁免与边界
- 仅当 PRD 明确本次需求覆盖一个以上客户端时才适用；单端需求（只做 Web 或只做 App）直接判通过（severity=none）。
- 不要求 PRD 为每条埋点重复写两遍 Web/App 明细，只要平台归属可被明确推断即可。
- 服务端/后台需求不涉及客户端埋点平台拆分，不在本检查范围内。
- 若 PRD **明确声明本次需求无需埋点**（如埋点/数据章节注明「本需求无需埋点」「无埋点诉求」），直接判通过（severity=none）；即使含「埋点」字样、跨多端，也不因平台未拆分而报问题。

## 输出格式
返回 JSON：`{"pass": bool, "severity": "P0|P1|P2|none", "location": "...", "description": "...", "why": "...", "fix": "..."}`。
