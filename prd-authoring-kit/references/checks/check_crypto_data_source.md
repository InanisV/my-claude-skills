# Check: 交易/行情数据来源

## 检查对象
涉及价格、数量、交易对、盘口、余额等字段的功能规格。

## 判断标准
- 通过：关键数据来源清晰，至少知道来自哪个系统、接口或数据域。用占位或「依赖某方提供的某类数据/接口」标注同样视为通过。
- 不通过：涉及交易或行情数据，但来源完全不明（既没说来自哪个系统/数据域，也没标明由谁提供）。

## 豁免与边界
- **不要求**字段级接口细节（接口名、调用方式、request/response 结构）；只要产品层能识别数据来自哪个系统/数据域或由谁提供，即通过。给出了契约细节属加分项，不作为达标基线。

## 输出格式
返回 JSON：`{"pass": bool, "severity": "P0|P1|P2|none", "location": "...", "description": "...", "why": "...", "fix": "..."}`。
