# Check: 成功指标量化程度

## 检查对象
成功指标、目标指标、效果评估相关章节。

## 判断标准
- 通过：成功指标至少部分量化，或有明确判定口径。
- 不通过：成功指标完全定性，无法判断是否达成目标。

## ✗ 典型不通过案例
- 只写“提升转化率”“改善体验”“提高满意度”，没有任何数值、时间窗口或判定依据。
- 写了“提升 10%”但未说明基准、统计周期或适用范围，属于量化不完整。

## ✓ 典型通过案例
- 提供具体数值、统计周期或分母口径，如“7 日内提交转化率提升 10%，基准为当前版本”。
- 即使是定性指标，也给出清晰判定依据，如“试用 PM 在评审期内未主动反馈使用障碍”。

## 豁免与边界
- 成功指标量化不足最多影响 P1，不应单独触发 P0。
- 上下文中的自然语言范围限定可视为分母口径的一部分，不要求全部公式化表达。

## 输出格式
返回 JSON：`{"pass": bool, "severity": "P0|P1|P2|none", "location": "...", "description": "...", "why": "...", "fix": "..."}`。
