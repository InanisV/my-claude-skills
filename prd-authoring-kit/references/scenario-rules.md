# 场景规则库（共建模板）

> 本文件是「需求 & 设计审查」工作流的**场景规则库**，由各业务线持续补充真实 case。
> 审查时会自动加载本文件，把这里的检查项叠加到通用维度之上。命中的条目在报告中会标注 `[场景库]`。
>
> **维护方式**：直接在对应业务线下新增一行即可，越具体越好（写清"检查什么 + 为什么 + 期望表现"）。

## 使用说明

- 每条规则尽量对应一个**真实踩过的坑**或**业务硬约束**，而非通用常识
- 字段：`场景` = 触发条件 / `检查点` = 审查时要核对什么 / `期望` = 正确做法
- 通用规则（多端覆盖、空/加载/错误状态、埋点等）已内置在工作流，无需在此重复

## 通用（全业务线适用）

| 场景 | 检查点 | 期望 |
|------|--------|------|
| 多端需求 | H5 / Pad / Web 是否都有设计 | 缺失端要么补设计，要么注明"无需单独设计" |
| 列表/行情类页面 | 是否有空、加载、错误、断网状态 | 四态齐全 |
| 涉及登录/权限 | 登录前/后、有无权限的差异 | 各态都有明确表现 |
| 数值展示 | 超长值（价格、涨跌幅、金额）处理 | 定义精度、千分位口径，多端一致（**截断/占宽属 UED，不写进 PRD**，见 `07 §二之二`） |
- **复用现有能力**（一键下单/弹窗/流程）：与对应负责人确认入口纳入其灰度与幂等即可。**版本兼容不要写进 PRD**（属研发域：客户端/config 平台自会做版本条件）——写了"最低版本上线前对齐"这类半句必被审查器咬"未给出数值"；只有产品明确要求特定版本差异行为时才写、且必须给具体版本号。

- **新增文案 ↔ Localisation 节必须一致（E 自洽）**：正文出现 新气泡 / 按钮 / 提示文案（尤其带 {N} / 占位符的动态词条）时，文末 Localisation Requirements 不得写"无新增文案 / 无需本地化"——两处矛盾会漏国际化配置（实测 P1）。有新词条就如实列进本地化范围。

## 高危链路与并存模式（2026-07 实测新增）

- **跳转真实下单入口的链路**（一键下单/交易计划页/快捷开仓）必写三件：①**是否自动触发下单**——默认否（进入页面由用户手动确认），若产品要自动触发必须显式写明并给失败/风控/未开户路径；②目标页归属声明（下单可用性与异常由目标页现有逻辑承接，本 PRD 不重复定义）；③返回定位。**"触发一键开仓"这类措辞会被读成自动下单**（实测 内审工作流 内审抓出，产品原意是手动）——写"进入 XX 页，由用户手动确认下单"。
- **按钮置 loading / 禁用后跳转，必写复位时机（B 闭环）**：任何"点击 → 置 loading / 禁用防重复提交 → 跳转"的交互，必须定义 跳转失败 / 风控拦截、及从目标页 pop 返回时该态如何恢复——路由栈 pop 会保留历史态，不主动复位=控件永久不可点（实测阻塞级）。置态即进入，必配对退出。
- **列表 + 插入模块并存**（feed 内插推荐位等）：必写空态优先级矩阵——列表空但模块有数据 / 列表空且模块无数据 / 列表加载失败，三种态各展示什么、插不插模块。
- **生成类功能**（分享卡/海报/导出）：必写生成失败降级（toast+不生成 或 缺件时占位图+流程继续），依赖数据缺失单独给兜底。
- **同一载体多角标**（头像 badge/卡片角标）：写**同屏冲突优先级**（谁压谁、能否并存）——这是产品口径；**具体挂哪个角、占多宽属 UED，不写**（`07 §二之二`）。

## 延迟触发 / 弹窗 / 计时类交互（2026-07 实测，内审工作流 高频抓；命中必填矩阵行）

这类"进页 N 秒后弹窗 / 定时触发 / 浮层 / 倒计时"需求，门禁常判「简单需求」轻松满分，但正是第二道门（08 §0.6 矩阵）重灾区。命中就把下列每格填齐，**空格 = 发布前问产品**：

- **计时起点 + 起点兜底（A 状态 / F 边界）**：起点是什么（进页 / 核心数据返回 / 前台可见）；**若起点依赖的数据迟迟不到或失败**——不弹 / 从进页时刻直接计时 / 最多等 N 秒？（别让"等核心数据返回才开始计时"变成"数据不来就永不弹"的死结）。
- **"上次 X"锚点必带首次兜底（A 状态 / C 分支）**：把 重试 / 周期 / 冷却 锚点定义为"上次 X 的时刻"（上次弹出 / 发放 / 同步）时，必须同时给"本会话 / 周期内从未 X 过"的首次锚点——否则首次永远等不到、研发瞎猜；默认兜底=进页 / 激活时刻起算。（区别于上条「计时起点兜底」：那条兜数据不到，这条兜首次无锚点。）实测：长驻重试锚点写成"上次成功弹出时刻"，漏了"首次没弹过"这一支。
- **计时中的状态迁移（B 闭环）**：离开页面、App 入后台 / 锁屏、页内轻量遮罩——各是 暂停 / 取消 / 重置 / 不影响？返回且前台可见 → 重新计时（且受频控约束）。
- **频控 vs 页面重入（E 自洽必查）**：本需求"切回重新弹" 与 "复用现有弹窗频控"（每会话 / 每天 / 跨页共享 一次）**谁优先**？先判全局频控、再判页面重入；给口径（如"跨页共享、每会话 1 次，会话重置才再弹"）+ 命中/未命中频控的验收用例。
- **内容就绪门槛（A 状态）**：计时到点但内容 未返回 / 空 / 字段不全——弹空壳 / 延迟等 / 本次放弃？给最小字段集作展示门槛（按对象类型定，如 资讯类=对象ID + 标题/摘要其一；活动类=活动ID + 主文案）。
- **端内 / 端外判定（C 分支）**：给"端内"的产品语义口径（App 内 WebView + 命中白名单路由）；端外（系统浏览器 / 第三方容器）一律不弹、页面正常显示；验收覆盖端内外两类。
- **弹窗内跳转 + 上下文（B 闭环）**：每个可点元素的目标页 + 必传业务上下文（视对象而定，如 交易类=币种/方向；内容类=对象ID/作者标识 等）+ 目标页无数据或上下文无效的兜底 + 登录要求（判据同 `08 §2`「上下文接得住吗」，此处只补"弹窗类"的落地）；纯归属声明"复用现有弹窗逻辑"须确认现有跳转覆盖了本页的新上下文，否则单独定义。
- **用户态曝光范围（C 分支）**：触达类（弹窗 / 横幅 / 浮层）必写**登录态 / 未登录态各是否曝光**、且**沿用现有触达逻辑还是本次新增**（别默认"登录才触达"或"两态都触达"）；若未登录可见，点击需登录的元素补 **拉起登录 / 登录成功落地目标页 / 取消登录回退原态** 三段，各给验收。
- **同页长驻重触发（B 闭环）**：除"进入 / 切回"外，**连续停留满一个频控周期是否重触发**要显式二选一——**不重触发** / **每满周期重触发 + 锚点（从何刻起算下一周期）+ 单页上限**（别让"只定义进入型触发"变成"进来触发一次、坐一天再不触发"的隐性缺口）；给命中/未命中的验收用例。
- **路由白名单匹配口径（E 自洽）**：给"命中白名单"的**匹配规则**（语言前缀算不算 / 大小写敏感否 / 尾斜杠算不算 / query 参不参与），白名单样例统一写成同一形态；**只给样例不给规则 → 各语种前缀、大小写、变体路由行为全未定义**（发布后各端各判一套）。

## AI agent / 内容生成管道类（persona·自动生成·机审·打分·机器人应答；命中任一即逐条过）

- **同主体同话题观点一致性**：同一 persona/agent 对同一话题·标的的观点**不得随次数漂移**（今天看多明天看空=人设精神分裂）——必须设计记忆机制（观点摘要/立场库：怎么落、怎么读、保留多久），跟进式生成必须带上历史立场。
- **可重复消费素材的队列模型**：同一素材（选题/热点）可多次触发时，明确 每主体是否独立消费队列、队列进出与排序、去重窗口、**队列为空时与保底产出链路的衔接**——只写冷却间隔不写队列=模型缺层。
- **生成失败/降级链**：生成失败·超时·素材接口不可用·审核不可用 各自的行为（跳过/重试几次/降级形态），**无素材时不得生成含数字内容**。
- **审核与质量闭环**：badcase 怎么采集回流、prompt 更新前用什么集回归、误杀与漏放各自的验收口径。
- **配额·节奏·防同质化**：日配额与切日口径（白话写清）、同标的/同话题产出上限、发布时间抖动、**防自举/防级联**（机器人互动不得触发再互动、不得给自己刷分）。
