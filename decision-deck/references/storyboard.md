# 故事板、预设骨架、讲稿、自检表

先写故事板，故事板过了再做页面。故事板是给 Yoki 预审的东西，页面是给会议室的东西。

## 1. 故事板模板

| 页号 | 观点句标题 | 视觉（类型 + 来源） | 反差 / 问题 | 价值块 | 口播三句 | 秒数 | 状态 |
|---|---|---|---|---|---|---|---|
| 1 | 封面：一句判断（框架名） | 封面三机页 | 开场问题写在副标题 | 三台手机各配一句 | 一句说判断，一句说问题，一句说今天讲三件事 | 40 | 草稿 |
| 2 | 第一件事的结论句 | 曲线加事件（数据来源） | 大数对比 | | | 60 | |
| 3 | 第一件事的原因句 | 两条路径并排 | 旧路径 vs 新路径 | | | 50 | |
| 4 | 第二件事的结论句 | 矩阵（真机核对日期） | 我们一列全叉 | | | 70 | |
| 5 | 第二件事的案例句 | 三栏真机截图 | | | | 60 | |
| 6 | 第三件事的提议句 | 三栏大手机（设计稿 / 概念稿） | | 右侧三块 | | 70 | |
| 7 | 第三件事的落点句 | 图加手机（最接近下单的位置） | | 底部三块 | | 50 | |
| 8 | 展望句（一句能被转述的话） | 价值总览（三列各一句结论） | | 每列两块 | | 40 | |
| 9 | 结尾动作（三问 / 选项 / 请求 / 路线） | 文字卡或路线页 | | | | 60 | |
| 附 1 到 3 | 弹药页：预判的三个追问各一页 | 全表 / 来源 / 口径 / 架构 chip | | | 被问到再翻 | 0 | |

填表规则：

- 标题列写判断句，有人能反对它才算；"XX 现状""XX 调研"不算标题；写成大白话，老板一遍能懂
- 价值块列写这页要让老板带走的两到三句大字，没有的页问自己是不是在堆功能
- 视觉列写类型和来源两段，来源写得出才能排进正文，写不出的页进附录或删
- 反差列可以空，但三件事里每件事至少有一页不空
- 秒数加总不超过场合时长的 90%，封面和结尾各 40 到 60 秒
- 状态列：草稿 / Yoki 过 / 定稿 / 砍

## 2. 四种预设骨架

每个骨架都按 E 哥四格标注页面类型。选一个再改，不混用。

### 调研类（脑暴会、方向会，会上讨论）

| 段 | 页 | 四格 | 视觉 |
|---|---|---|---|
| 封面 | 问题做标题，三个大数做反差 | 结果 | 封面页 |
| 别人为什么赢 | 他们的路径变了（旧 vs 新）；三个拐点、三种距离 | 结果、原因 | 路径对比页，曲线加事件页 |
| 跟我们有什么关系 | 三类玩法并排；功能矩阵我们一列的差距 | 风险 | 三栏页，矩阵页 |
| 我们怎么做 | P0 一页，放在最接近下单的位置；再一页承载和传播 | 资源 | 手机帧页 |
| 展望 | 一句能被转述的话，三条变化 | 结果 | 三卡页 |
| 讨论 | 三个问题：凭什么赢、第一批从哪来、第一期先做什么 | 资源 | 讨论页，可加观点看板 |

### 方向类（CEO 同步、认可方向、规划同步）

2026-10-23 定稿的广场规划 deck 就是这个骨架，10 页正文加 5 页附录。

| 段 | 页 | 四格 | 视觉 |
|---|---|---|---|
| 封面 | 一句判断（三个口号）做标题，开场问题做副标题，三台手机各配一句预告三步 | 结果 | 封面三机页 |
| 别人和我们 | 头部平台都带上了交易，我们还没有：左边三家真机，右边我们的真机加两块大字 | 结果 | 合并页 |
| 三步 | 三台大手机加箭头，每台上面是步骤名，下面是时间 chip | 资源 | 三步页 |
| 第一步 | 格局句标题；三台大手机连成一条流程，右侧三块价值 | 资源 | 三栏大手机页 |
| 第二步 | 格局句标题（人人都是交易者）；三台大手机，右侧三块价值 | 资源 | 三栏大手机页 |
| 第二步的延伸 | 格局句标题（每个币种页都是一群真实持仓的人）；图示加手机，底部三块价值 | 原因 | 图加手机页 |
| 第三步 | 和既有产品的区别写在标题里（跟单管执行，圈子管关系）；图示加手机，底部三块价值 | 风险 | 图加手机页 |
| 第三步的延伸 | 不大言不惭的能力句（可以跑在圈子上：赛完，人还在）；一张图示，底部三块价值 | 原因 | 图加价值带页 |
| 三步之后 | 三列各一句结论，每列两块支撑 | 结果 | 价值总览页 |
| 路线 | 一句能被转述的话做标题；三期三条错开的色块，模块做 chip | 资源 | 路线页 |
| 附 1 到 5 | 基础件矩阵、供给三轨、边界四条、分层架构 chip、竞品做法与时间线 | | 附录页 |

每页标题下一条三段步骤带，当前段亮色。认可方向的场合，路线页后面加一页一句请求；规划同步的场合，到路线页为止，不写请求，不写需要的支持。方向型不写验收方案，不写执行时间表，不留"请拍板"。

### 拍板类

| 段 | 页 | 四格 | 视觉 |
|---|---|---|---|
| 问题 | 为什么现在要定 | 结果 | 文字卡加一个数 |
| 结构性差异 | 两个方案的一个本质差别，优缺点从它推出来 | 原因 | 反差页 |
| 选项 | A 和 B 镜像呈现，各自参考、各自代价，字数对齐 | 风险 | 选项页 |
| 倾向 | 我们倾向哪个、理由一句；他不同意会自己说 | 资源 | 文字卡 |
| 需要定的 | 一句：定 A 还是 B，什么时候要 | 资源 | 文字卡 |

### 成果类（季度）

| 段 | 页 | 四格 | 视觉 |
|---|---|---|---|
| 结果 | 每个数带基线（从多少到多少）和归属主线 | 结果 | 大数页 |
| 原因 | 数字为什么动，归到哪条动作 | 原因 | 曲线加事件页 |
| 风险 | 没达成的、看不准的、依赖别人的 | 风险 | 三卡页 |
| 下季资源 | 一处请求，写清影响哪一期 | 资源 | 文字卡 |

数字口径和归因来自 okr-report，这里只管顺序和密度。

## 3. 讲稿模板

```
P3｜（页标题原文）
一、一句话说标题的意思（口语，不读页面）
二、一个案例或一个数（有来源）
三、落回观点，或一句话引到下一页
秒数：50
```

- 每页三句，多了就是这页有两个观点
- 术语能换口语就换：不说"分发网络"，说"赢家发内容，别人跟着买"
- 结尾三问，每问自己先写一句倾向，不上页，只在讲稿里
- 讲稿和标题是读者的 AI 读到的全部内容，两者都写成判断句

## 4. 交付前自检表

逐条打勾，有一条不过就回去改，不交。

主线
- [ ] 一句判断写得出，是框架名不是功能描述
- [ ] 标题串读成一段能单独成立的论证
- [ ] 三件事不多不少，第四件在附录
- [ ] 一句判断在封面、每页的步骤带、价值总览页各出现一次；任何一页都看得出属于哪一步

逻辑
- [ ] 每页是上一页的"所以"
- [ ] 结果、原因、风险、资源四格齐

观点
- [ ] 每个标题有人能反对
- [ ] 没有"XX 调研""XX 现状"式标题

页面
- [ ] 一页一个视觉；视觉优先级从视频往下取
- [ ] 标题不超过 20 字，是大白话，关键结论一处高亮
- [ ] 正文页没有小字：没有来源行、要点说明、图注、模块标注、左上角 kicker；说明句 22 像素以上白字一行
- [ ] 页面撑得住：手机缩放 0.76 以上，三台之间有箭头，价值块在右侧或底部；两页都空就合成一页
- [ ] 每个功能页有两到三块价值，按内容从哪来、用户为什么来、交易和收入从哪来写
- [ ] 标题用格局句，不随便、不巧、不绝对、不大言不惭
- [ ] 无 emoji；中文标点；禁词表过；没有别的团队的词和项目名
- [ ] 概念稿有"概念 · 示意数据"水印，设计稿写"设计稿 · 示意数据"；真机截图在附录标产品、端、日期

反差
- [ ] 每件事至少一处反差，两端都可核

证据
- [ ] 大数有来源小字；全表和口径在附录
- [ ] 没数的词不上页；无装饰数字；同期对照不写因果

时长
- [ ] 秒数加总不超过场合时长的 90%
- [ ] 彩排读秒两遍

结尾
- [ ] 动作匹配场合：讨论三问 / 带代价的选项 / 一句请求 / 规划同步以路线页收，不写请求和支持
- [ ] 三问各有自己的倾向写在讲稿里
- [ ] 弹药页三页在附录

读者
- [ ] 交付前以老板视角列五个会被问到的问题（和既有产品的区别、第一批供给从哪来、现状数据、要多少资源、为什么不和别的项目一起做），答得上的改进页面，答不上的向用户要数字
- [ ] Yoki 预审过，两轮内
- [ ] 给 E 哥的过了 ealy-pitch 禁忌表，不带日期戳、不引他原话、不写政治词
- [ ] 被转发的人能从第一页进
- [ ] 把所有标题和讲稿喂给 AI 做摘要，摘要是正面的
