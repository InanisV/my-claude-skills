# 10 · 防过拟合：三层规则与参数化清单

本 kit 从一条片子里长出来。为了不把一次的选择当成所有片子的规矩，所有内容分三层。执行时先确认一条规则属于哪一层。

## 1. 通用规则（任何产品、平台、受众都成立）

- 先交付合同再开工；授权按项目记录。
- 先选形式，形式级改动先出 animatic；分镜阶段预算不低于生产，评审不过不进生产。
- 生成模型只做氛围，不做事实；精确 UI、文字、数字走真素材、复刻、程序绘制。
- 先声后画；逐句配音、独立听写、仪表初选、人耳终选。
- 三条确定性：图片序列、整数帧、时间线动画。
- storyboard.json 唯一真源；按镜修改；换声不重渲。
- 从最终编码文件验收；失败保留；三件事分开写。
- 常驻裁量权；人工介入固定四处。
- 卡片碰撞、阶段串行、版式轮换、无旁白窗口、结尾收束这类结构规则。

## 2. 项目参数（每个项目重新定，写进 brief 和 storyboard，不写进 kit）

| 参数 | 本次项目的值（仅作示例，不是默认） | 怎么定 |
|---|---|---|
| 片长 | 内部 52 秒、外发 42 到 44 秒 | 合同与片型 |
| 拍数与各拍时长 | 9 拍 | 事件与渠道 |
| 音色 | 中文云扬、英文 Davis（平台名称按实际界面） | 两到三个试音 + 人耳 |
| 语速 / 音高 | 原生 1.0、-5 Hz 档 | 仪表 + 人耳，以实际档位落盘 |
| 配乐 | 某首 110 BPM 极简电子 | 规则初选 + 试混人耳 |
| 音效次数 | 6 次 | 按叙事转折 |
| 色温弧线 | 7000K → 4500K | 片型 |
| 镜头与生成模型 | 某平台的 Seedance 2.5 等 | 侦察与对打 |
| 复刻页面清单 | 8 个页面 | 分镜需要 |
| 事实数据与竞品点名 | 某币上线日期、"早两周" | 只用有来源、有人认可的口径 |
| 交付格式 | GIF 720p/10fps < 25 MB 无声 | 合同 |
| 路径、画布、资产 ID、工具可执行路径 | 本机快照 | 每次核实，不写进 kit |

motion-prompt 的编号是词汇不是规则："揭晓必须用 #017"是过拟合，"揭晓的转场要有名字、时长和缓动"才是规则。

## 3. 一次性实验（可选项，写在 08 末尾）

绿幕屏幕替换、视频编辑模式精修、多模型对打、参考片节奏学习、特定结构分析库。

## 4. 执行时的自检

- 任务书里出现"一定选某音色 / 所有片子 N 秒 / 音效必须 N 次 / 所有 GIF 25 MB"这类句子，说明把项目参数写成了规则，改回"按合同 / 按试音 / 按叙事"。
- 任务书里出现上一个项目的路径、币名、数据、画布 ID，说明忘了参数化。
- 任何"全部门禁通过 / 某库已成功 / 参考模式能保住文字"的说法，先回看证据再写。
- 同一规则在三个以上项目里都成立，再从第 2 层提到第 1 层。
