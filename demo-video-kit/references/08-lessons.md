# 08 · 十轮迭代的坑（按主题，附可选实验）

每条写"现象 → 原因 → 规则"。规则已进各 reference，这里是来处，新坑按同格式追加。

## 形式与导演

- 分镜草率：第一版只写了一个结构就开渲，之后四轮在参数上打磨，直到清零重做分镜分数才跳上去 → 分镜阶段预算不低于生产；三个候选主线；十项评审不过不进生产（11）。
- 运动靠形容词："推进一点、飞进来"每轮做出来都不一样，人也无法预判 → 运动与转场用名字加编号指挥，动态预演先于内容（12）。

- 第一版像教程：录屏放进悬浮手机壳 + 标语 + TTS，调了四轮版式字号光照仍"差点意思" → 形式决定上限 → 先选形式，形式级改动先出 animatic。
- 观众走神：十拍同一构图、旁白占满 54/60 秒、音乐全程被压 → 没有对比就没有张力 → 三种版式轮换、三个无旁白窗口、动作到结果硬切。
- 功能单薄与功能堆砌都发生过：四拍太少被说薄，六项蒙太奇被说"把基础功能当宝" → 发布片讲一个事件，功能在线上"被用到"；内部帖和成片都不列功能清单。
- 钩子倒退：为了和真实图表押韵，立体玻璃折线被换成细霓虹线，还先跌后涨 → 押韵保留、材质不能丢、开场方向向上。
- "乱"的开场：十二张卡互相压、文字被裁、收卡与亮屏同时发生 → 卡片碰撞规则、三个禁区、阶段严格串行。
- 结尾戛然而止：最后一句说完两秒就黑 → 最后一句距片尾 ≥ 3 秒、音乐单调下降、定格后再黑。
- 第 8 拍"规划中"的虚线节点被要求删掉 → 面向内部老板的片子只讲站得住的事实，规划不进画面。

## 生成模型

- "candlestick" 被三家图片模型画成实体烛台 → 金融术语在提示词里要换成不歧义的描述（price chart / rising zigzag）。
- 参考生视频把用户名和布局重写、首帧模式裁切模糊、数字动画 127→126→127 → 生成模型不碰事实层。
- 一句话提示词出来的全是推拉 → 七要素提示词、禁用清单。
- 生成镜头末尾不停、开头黑 → 用真实末帧定格、裁掉黑头，不假设模型会"停稳"。

## 平台与 Computer Use

- 点了节点上的停止按钮误取消任务；复制节点继承旧预览误判成功；下载打开了媒体标签页而不是触发下载；文件无后缀、PNG 后缀实为 JPEG；少数下载被安全策略拦下 → 04 第 2 节纪律。
- 平台菜单可见不等于实测可用；10/10 成功不等于长期 100% → 事实与推断分开写。
- Figma 官方 MCP 需付费席位 → 用已登录的桌面端 Computer Use。

## 素材

- 严格 avoid 让四个镜头交空 → 标记三级，候选永远输出。
- 6.17 秒超 6 秒上限 0.17 秒被判不完整 → 时长区间是指导值，正负 20%。
- 环境提示条、悬浮球、红色录屏指示出现在所有帧 → 录屏规范（数据线录、关悬浮球），复刻界面去掉环境提示。
- 全局 hash 把打字误判为停留 → 局部相关估位移。

## 渲染

- 隔帧重复等效 15 fps（变速段走 video seek）→ 图片序列。
- 浮点帧号取整取到前一张（环境 537 次、CTA 51 次偏差）→ 整数帧驱动一切。
- 随机 seek 与顺序 seek 不一致 → 回归测试，必要时预热。
- 3D 倾斜让界面文字糊 → 阅读时段 2D。
- 普通 1 倍截图在 1080p 里界面文字 8 像素 → 2 倍超采样 + 特写构图。
- 磁盘 4 GB 时渲染 4K → 流式管道、背压、逐拍查门限。
- 改了冻结范围内的源码使全部缓存失效 → 先想数据层改动。

## 声音

- 英文播音音色念中文（"广场"读成"现场"）→ 母语音色。
- 云希 0.8 速度阴阳怪气 → 沉稳靠音色和句尾，不靠慢。
- 本机系统 TTS 占位进了 animatic 被当成真实配音 → 汇报必须写明占位。
- 42 次提示音叠在同一瞬间 → 音效预算按叙事转折。
- 平台语速音高是步进档位 → 以实际参数为准落盘。
- 免费档第三方的接口权限、付费能力、音色许可是三个问题 → 分别诊断，外发只用公司授权音色。
- 结构分析库装不上 → librosa 替代并写明未认证。

## 交付

- 只能传 GIF、25 MB 上限最后才知道 → 交付合同在开工前。
- 压小 MP4 四次都没解决未知报错 → 先问报错原文。
- 大 GIF 调色板一次性堆帧爆内存 → 两步全局调色板、流式。

## 协作

- 指挥者在对话里替执行者选段打分，执行者那边的 skill 就跑不起来 → 判断全在执行者里做；任务书每次整份。
- 规则写成门禁没有裁量权，执行者遇冲突就停或交空 → 常驻裁量权条款。
- 凭据粘在文本窗口被屏幕读取 → 终端隐藏输入写 `.env`，只由进程读。
- 发群消息引用了另一个群里老板的话，读者不知情 → 对外的消息只说做了什么、接下来做什么。

## 可选实验（验证过可行或部分可行，不是流程）

- 绿幕屏幕替换：生成"屏幕为纯绿平面"的设备，OpenCV 逐帧检测四边形并单应性贴真实界面；稳定段约 2 秒，边缘绿线和地面反光需去溢色。
- 程序粗渲染 + 视频编辑模式加材质：保结构较好但改时长和过渡，必须 OCR 守门。
- 多模型对打：同镜头跑多个模型让评分表选；模型擅长的镜头类型因平台而异。
- 参考片节奏学习：用场景切分统计参考发布片的镜头时长分布当目标，比拍脑袋定秒数可靠。
