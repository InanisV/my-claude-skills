## 1. 什么时候复刻、什么时候真机

- 真机录屏：教程片的主体；发布片里做"真实感落点"（结尾真实入口）和图表类纹理（K 线页真实截图）。
- 复刻界面（HTML 组件）：发布片的舞台。好处是无模糊、无环境提示条、无悬浮球、可任意缩放和三维摆位、可动（翻转、飞入、翻译、计数）、换语言只换字符串。
- 混用规则：同一镜头内不混切来源；以拍为单位选择。真机录屏的滚动速度曲线可以测出来喂给程序滚动，保留"真机手感"。

## 2. 复刻界面的真实性边界

- 几何来自设计稿或真实截图手量，布局锚在 2 像素内；内容（帖子文本、用户名、数字、胶囊）来自录屏索引和 OCR，用户名只用已出现过的。
- 文字全部真实字体渲染，不是图片；图表区域例外，用真实截图纹理。
- 每个页面与真实截图并排出对比图，差异只允许在内容层，不允许在布局层；字体、矢量图标、装饰的近似要写明，不宣称整页像素一致。
- 复刻版去掉环境提示（地区限制条、引导条），它们不是产品。
- 叙事里的新帖、计数、回复、关注是演示情境，报告里写明不是录屏里真实发生的历史行为。

## 3. 渲染器契约

- 技术栈：HTML + CSS + 时间线动画（GSAP）；无头 Chrome 逐帧截图；ffmpeg 装配。零付费依赖。
- 图层从下到上：环境底（静帧或生成视频）、舞台（复刻界面或真机图片序列）、文字层（标题、价值句、字幕、字卡）、品牌层（logo、角标、叙事钟）。
- 一切动画走时间线，禁用 CSS transition / animation；渲染脚本对每一个整数输出帧执行 seek，再截图。
- 视频素材先抽成 30 fps PNG 序列，按帧号取图；变速用 `setpts` 后再 `fps=30`，禁止重复帧做慢放。
- 等待字体、图片、绘制稳定后再捕获；黑场在编码前明确画 RGB 0，首帧强制 IDR。
- 色温弧线、版式、光带位置都是 storyboard 字段，渲染器只读不猜。

## 4. 取帧与 seek 的非显然问题（都踩过）

- `<video>.currentTime` 加 `seeked` 不可靠：会取到上一帧，变速段出现隔帧重复（等效 15 fps 卡帧）。图片序列根治。
- GSAP `seek(t)` 不天然保证任意跳帧等于顺序播放：重叠 tween 懒初始化会造成差异；做随机 seek 与顺序 seek 回归，必要时按正式顺序预热再归零。
- 浮点帧号向下取整会取成前一张（`528.999999`）；统一以整数输出帧驱动时间线、计数和取图，修后索引偏差为 0。
- 图片序列修的是取帧确定性，消除不了录屏里真实的阅读停顿；源局部重复、全画面重复、编码噪声、人为读字停留要分开报告。

## 5. 清晰度工程

- 阅读时段只用 2D 缩放和位移，禁止 3D 倾斜；倾斜只在子镜头切换的 0.3 秒内。Chrome 对倾斜的视频做重采样会糊。
- 屏幕区域不叠暗化、反光、玻璃层；屏幕内容亮度 1.0。
- 逻辑画面 1920×1080、deviceScaleFactor 2 截图 3840×2160；同一 PNG 管道双路编码：4K CRF 18 和 Lanczos 缩回 1080p CRF 16（`-tune film`）；AAC 192k。
- 不把整片 PNG 常驻内存：流式管道，逐帧元数据写带背压的 NDJSON.gz，完成后再哈希。
- 验收：UI 子镜头屏幕区域拉普拉斯方差不低于上一版同镜头的 1.5 倍（只用同源同帧基线）；特写帧屏幕 OCR 识别出预期文字 90% 以上。

## 6. 缓存、冻结与按镜重渲

- 缓存签名分开绑定：画面依赖、音源与位置、静态源码快照、素材 SHA、时间域。同画面换旁白不重渲。
- 冻结：story 与源码、素材一起 freeze，生成 proof；跨分支复用必须验证实际视觉依赖相同并保留原 capture 身份，不把复用假标成重新捕获。
- 修改冻结范围内的渲染器 / 组件 / 资产会改变全局快照，可能使全部缓存失效；先判断能否只改数据层。
- 子镜头缓存边界多渲 2 帧余量，拼接时核对边界帧连续。
- 磁盘预算：逐拍开工前查门限；只清明确可再生、无占用的缓存；不删原片、模型、终稿、登录配置。

## 7. 参考实现

本 kit 不附带渲染器代码。上一个项目的实现在 `$VIDEO_KIT_ROOT/<project>/renderer/` 和 `tools/`（schema、provenance、render、freeze、mix、assemble、actual_qa、ui_event_qa、text_qa），大量路径和文件名硬编码在项目里。新项目第一次用时先把项目根、分支、音色、平台、格式参数化，再决定复用范围；不要为了读懂项目直接重跑整条流水线，构建脚本可能覆盖后来手工修正的内容。
