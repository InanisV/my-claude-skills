## 1. 问题

"推进一点、飞进来、有点张力"这类描述，执行者每次做出来都不一样，人也无法在渲染前预判。导演和摄影师之间靠的是名字：dolly in、mask reveal、match cut。名字带着时长、幅度、缓动的默认值，说出来就是规格。

## 2. motion-prompt（MIT）

https://github.com/showheyohtaki/motion-prompt ：144 个带动态样本的名字，六个包：motion（动效）、camera（运镜与转场）、ui（界面部件）、lp（网页演出）、photo（光与风格）、motion2。每个名字有一行定义、一句"怎么向 AI 要"的范例、时长与缓动参数、以及 Canvas 2D 的参考实现。参考实现是"只由时间决定画面"的纯函数，不读时钟不用随机数，所以逐帧渲染和实时播放得到同样的帧，与本 kit 的确定性渲染器天然兼容。

安装（执行者环境）：`npx skills add showheyohtaki/motion-prompt`，或把仓库里 `skills/motion-prompt` 拷到 `.agents/skills/` 或 `.claude/skills/`。装好后说"打开 motion-prompt 库"会在浏览器开画廊，选了按"发给 AI"；知道编号可以直接说"用 #012 和 #045"。

## 3. 在本 kit 里怎么用

- 分镜表的"运动"和"转场"列用它的名字加编号写，例如：揭晓 = #017 mask transition（0.7 秒）+ #022 light sweep；穿行 = #027 dolly in（沿信息流）+ #016 parallax；发帖 = #006 typewriter + #007 count-up；翻译 = #021 flip；主页 = 卡片 stagger 入列 #002；K 线 = 页面推入（自建 pack）。
- 时长、缓动、幅度沿用样本发布值，只换内容、颜色、图像；改了参数要在分镜表里写明。
- 执行者在渲染器里重建这些运动（Canvas / CSS / 时间线），汇报末尾列出用了哪些编号、放在哪一镜、改了什么。
- 动态预演（11 第 6 节）直接用样本拼，先看运动语言成不成立再做内容。
- 不确定叫什么时，把画廊当词典打开，不要凭空造词。

## 4. 为本片型建自己的 pack

motion-prompt 自带"做你自己领域的名字库"的提示词（`make-your-own/`）。给产品发布片建一个 pack，把这条片验证过的招式变成带样本的名字，下一条片直接点名：

| 名字（示例） | 含义 |
|---|---|
| 卡片变帖子 | 散落的消息卡加速汇聚，亮屏一帧变成列表内容 |
| 下拉展开 | 下拉手势收走碎片，页面从设备里展开成整幅舞台 |
| 一列穿行 | 相机沿单列内容推进，目标项前浮 |
| 页面推入 | 新页面从右侧滑入覆盖，底层后退变暗 |
| 胶囊涟漪 | 点击位置一圈涟漪，硬切到结果 |
| 发布回流 | 新内容从顶部滑入列表，计数跳动 |
| 翻面翻译 | 卡片沿纵轴翻面，另一面是另一种语言 |
| 堆进主页 | 卡片缩小堆进个人页列表，通知从顶落下 |
| 光的揭晓 | 转正瞬间一次白蓝闪加泛光，logo 同框落定 |
| 夜到晨 | 全局色温从冷到暖的逐帧插值 |

建 pack 的要求：每个名字一个只由时间决定画面的函数、一行含义、一句怎么要、时长与缓动默认值。样本进 `look/` 或独立仓库，新项目参数化后复用。

## 5. 把名字转成生成模型的提示词

生成镜头的提示词七要素里"镜头"和"运动与节奏"两项，直接用 camera 包的名字翻译：例如 #027 dolly in → "slow dolly in toward the device; move the camera, do not zoom"；#042 match cut 用来描述与下一镜的形状对位。名字比形容词更能被视频模型执行，也更容易在候选评审里判断"做到了没有"。

## 6. 边界

- 名字库是词汇，不是风格；每个包有自己的样本配色，进成片的颜色和字体仍用本项目的 token。
- 编号只在分镜表里当引用，不写进 kit 规则（"揭晓必须用 #017"是过拟合）。
- 样本是 Canvas 2D 参考实现，复刻界面的三维舞台里要用时间线等价重建，保持时长和缓动一致。
- 词汇库本身在演进（名字和编号可能增减），分镜表里同时写名字和编号，以名字为准。
