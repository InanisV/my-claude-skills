# 09 · 任务书模板（指挥者模式）

指挥者在对话里出完整任务书，执行者（Codex / Claude Code + Computer Use）照做。原则：每份任务书自包含、可整段粘贴；判断全部交给执行者；人工停点写明；产物和汇报格式固定。下面每个模板按需填空，不要只发"改动几行"。

## 0. 每份任务书共有的开头

```
> 跑到 <交付物> 产出才结束。工作目录 <$PROJECT_ROOT>。平台操作手册 <路径>。

## 0. 裁量权、授权与安全
- 时长区间正负 20% 自定；规则冲突选最接近意图的解并在 run-log 记"冲突、选择、原因"；交当前最好版本并标注缺口，不交空。
- 只在登录、验证码、权限弹窗、无替代的输入缺失、明确留给人的决定时停。
- 授权按 brief/decisions.md；密钥只从 .env 由进程读取，不打开不截图不回显。
- 全程续写 run-log.md。
```

## 1. 平台侦察

目标：产出 recon-report.md 与 platform-playbook.md。内容：安全边界（只自己画布、测试素材）、侦察清单（入口与组织、模型与模式、产出与下载、吞吐、三个保真度实验、已知坑）、手册格式（前置、操作、成功判定、失败处理、耗时）、批量运行规范、交付与 10 行汇报。测试素材由人准备三样：一张公开截图、一段 5 秒录屏、一张透明底 logo。

## 2. 素材理解与选段

目标：footage-index、功能清单、每镜三候选、补录清单。内容：输入与目录、规范化、分段、语义标注、镜头需求表（JSON，见 templates/shot-needs.json）、标记三级与打分、拼接与余量、导出、复核材料。补录文件单独索引。人复核格式写明。

## 2b. 分镜（投入最大的任务书）

目标：研究文件、三个候选主线与 logline、beat sheet 与能量曲线、每镜一行的分镜表（运动与转场用 motion-prompt 名字加编号）、关键帧板、动态预演、十项自评表；停下来等人选主线和看板。内容：按 11 的九节逐项列产物；禁止只写一个候选；禁止在评审前渲染任何正式画面；写明人复核格式（"主线选 B"、"S04b 的运动换成 #027"）。

## 3. 风格静帧测试

目标：三个方向各三个镜头、每镜多模型静帧，拼图加十项评分，停下来等人选方向。内容：方向表（世界观、材质与光、镜头语言、风险）、七要素模板与范例、禁用清单、评分表、任务矩阵、操作要点。执行者不自行进入动画阶段。

## 4. 冲刺（animatic 或完整版）

目标：animatic 或成片。内容：决定项（方向、音色、配乐）、形式规则、复刻界面、分镜表（拍 / 秒 / 画面运动 / 旁白 / 文案 / 声音）、旁白规则与试音、音乐规则、剪辑规则、渲染与仪表、质检、交付清单、10 行汇报。两步法：第一步 animatic 停下来等人，第二步完整版。

## 5. 定点修改

目标：只改列出的拍。内容：改动类型与重做范围（00 第 4 节表）、各拍具体改法、不动的部分逐包继承、自动检查新增项、交付。写明"其他拍不重渲"。

## 6. 导出与上传排障

目标：按交付合同导出。内容：合同三问（介质、大小、报错原文）、从原生源导出、GIF 规则、验收字节与余量、交付说明（无声、内部）。

## 7. 汇报固定格式（每份任务书末尾）

```
最后 10 行以内汇报：<交付物规格>、<关键门禁结果>、<未过项>、<本轮三个坑>。
我复核时只会说："第 N 拍怎样"、"用 voiceB"、"换 musicB"。按拍号改，不重跑全部。
```
