# 案例：广场热点方案（给 CEO，2026-10）

通用规则在 SKILL.md，这里只记这一份方案是怎么落的，供对照，不供照搬。

## 背景

CEO 最初要的是一个股票 Meme 专区。做专区的过程中，leader（Yoki）给了三阶段：归类已有内容、上币即起话题、去站外找热币反向推上币；她抓老板的点是"早发现让用户愿意来，也能推动早上币"。用户（Tom）的顾虑是没上币的讨论没承接。两边都对：leader 的三阶段做骨架，承接顾虑放进第三阶段内部写成"候选 → 关注 → 上币那一刻推送 → 首日交易"。

## 定稿一图流（examples/onepager_B_广场热点方案.html）

- 引子：股票 Meme 专区正在上线，它背后是一套能力
- 标题：让用户为「早一步」来 MEXC：热点先上两周，广场让它先聊、先买
- 左块：专区在做，两帧界面，路径"首页置顶 → 专区 → 下单"
- 中块：发现，大数"早 2 周+"，四根柱子，红 0"领先期里站内的讨论阵地"，三个图标的两轴逻辑
- 右块：提议，三帧三步，早发现金框，时间线"上币后 → 上币当天 → 上币前"
- 下半张：以后再来一个 PONS，它这样走。四步各一句情节，脚下模块标签带分期圆点，"23 个模块 · 3 期"
- 底部：热点在 MEXC 先聊先买 / 每次上币有人聊有人买 / 美股 Meme 这类题材随时能接 / 上币团队多一份站内参考

## 定稿文档（examples/doc_prompt_广场热点方案.md）

摘要 → 1 市场的节奏变了，上币早只打了一半（"供给早，注意力晚"）→ 2 证据表 + 两轴表 → 3 三步 + 3.1/3.2/3.3（画板）→ 4 四层表 + PONS 四步 → 5 价值与衡量 → 6 风险与边界 → 7 节奏与需要的支持（一期 🟩🟩⬛⬛；支持只写数据采购评估）→ 8 希望得到认可的事 → 附录术语、数据口径。

## 证据（examples/evidence_上币领先天数.csv）

MEXC 合约接口 openingTime 对币安上币公告，8 枚热点币无反例，平均早两周以上。

## 这一役的几个转折

1. 从"广场差异化"改成"他要的专区在做，做的过程中发现更大的事"：读者起点
2. 从三张牌改成一张真牌：没依据的删
3. 从架构清单改成"PONS 走一遍"：故事线做主线
4. 从用户问卷改回架构：用户数据只在证据块
5. 从"可能的追问"改成"风险与边界"：方案不做问答
