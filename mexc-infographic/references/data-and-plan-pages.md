## 一、数据与行动项页（1920×1080）

```
标签：MEXC 广场 · 数据同步 · 数分看板截至 M/D
标题：好消息在前（蓝色实色块）+ 接下来看什么
┌ 图表卡 1230 宽 ─────────────────────┐ ┌ 指标卡 510 宽 ┐
│ 柱 = 访问人数（低饱和蓝，不标绝对值）    │ │ 好消息：蓝框  │
│ 线 = 点击率（参考指标用浅灰粉，不用红）   │ │ 大数只放率    │
│ 放量阶段用底色带 + 虚线分隔              │ ├───────────────┤
│ 右上角一个胶囊：M/D 已全量 · 数据下周同步 │ │ 参考指标：灰框 │
└───────────────────────────────────────┘ │ 加「参考」小标 │
┌ 行动带 1760 × 404 ───────────────────────┴───────────────┐
│ 标题：三个问题，和对应的解法                                  │
│ 表头：问题 | 解法 | 进展                                      │
│ ① 白色实心编号 + 问题（29px）→ 蓝色实底图标 + 解法（27px）→ 进展胶囊 │
│ ② …                                                           │
│ ③ …                                                           │
└──────────────────────────────────────────────────────────────┘
```

骨架规则：
1. 标题先讲成绩，再讲接下来看什么。点击率这种参考指标不进标题，不然老板把它当 KPI 看，掉一点就慌。
2. 指标卡只放率（+34%、7.1% → 4.5%），绝对值小的数字不上图，图表的人数刻度也去掉，柱子只看趋势。
3. 指标卡下面一句话各回答老板的一个追问："同样 50% 放量，第二周比第一周"（是不是放量带来的），"广场以浏览为主，刷帖不一定点进详情"（点击率为什么只作参考）。
4. 行动带是问题 → 解法 → 进展，不是功能清单。每行一句话，不写说明句。进展用胶囊流水线：
   - 已完成：白底描边 + 对勾（评审、已和数分对齐）
   - 排期中：描边（研发 10/29、提测 11/04）
   - 上线日期：蓝色实底（上线 11/13、预计本周五 10/30 更新）
   - 卡住：暗红实底「待排期」+ 暗红描边写真实原因（后端仅 1 人，在做更高优需求）
   - 还没动：虚线描边
5. 没上线的功能名不出现（话题），写动作（运营指定热点，AI 账号集中发帖）。
6. 行动带是全图字最大、最醒目的部分，图表和指标卡为它让高度。

## 二、双线规划页（1920×1080）

```
标签：MEXC 广场 · 产品 × 运营            右上角胶囊：界面小图为示意
标题：广场的长期规划：产品把[交易变成内容]，运营把[内容做成生态]（两个蓝块）
┌ 主卡 1760 × 700 ─────────────────────────────────────────────────┐
│ 表头：两条线 | 2026 Q4 · 现在（蓝实底）| 2027 Q1 | 2027 Q2 起 → 长期 │
│ 产品线   ① 阶段名 + 场景句 + 小图 → ② … → ③ …   （第一格蓝框）     │
│ 交易变成内容                                                      │
│ 运营线   ① 阶段名 + 场景句 + 小图 → ② … → ③ …   （第一格蓝框）     │
│ 内容做成生态                                                      │
│ 内容品质  [AI 内容(蓝实底) → 审核与词库 → 优质推荐 → 数据复盘] 虚线绕回 │
│ 一直在优化  横跨三列，蓝框                                          │
└──────────────────────────────────────────────────────────────────┘
┌ 底层基建 · 两条线共用：九个能力胶囊一行排开（不写状态）─────────────┐
```

骨架规则：
1. 两条线同等分量：运营的规划是自己的一行，有自己的阶段名、场景句和小图，不是产品三步下面的一行（职场问题，Tom 定的）。
2. 阶段名下面是场景句不是 slogan："下单发、平仓发、高光时刻发、系统提示发"，不写"每一笔真实交易都是内容"。运营的也一样："先请品牌、预测市场、SEO 现成的 KOL 发帖"，不写"种子用户、种子 KOL"。有了场景句就不再挂标签。
3. 每格一张小图（交易卡、交易者主页、圈子、官方帖、创作者池、优质创作者榜），中性配色，只有按钮用品牌蓝。
4. 内容品质单独一行横跨三列：它不属于哪一期，而是一直在做。四个节点各写一句具体在做什么（修管线，批量更新人设 / AI 分级 + 敏感词库 / 真人优质帖优先曝光 / 看板补发帖、讨论、停留）。这是老板平时感受不到的工作，必须让他看见。
5. 高亮只有：标题两个蓝块、两条线正在做的第一格蓝框、2026 Q4 蓝实底、内容品质蓝框和 AI 节点。其余中性。
6. 近期行动项不放这张图，放数据图；这张只讲长期（堆在一起会被判"过于杂乱"）。
7. 底层基建不写状态，只列能力；审核与词库已在品质循环里，不重复出现。

## 三、两张图的共用语法

- 标题关键词：品牌蓝实色块 + 白字，padding 0 14px，圆角 12px。
- 卡片：#14171C 底，1px rgba(234,236,239,.09) 边；重点卡 2px 品牌蓝边 + 淡蓝渐变底。
- 编号：34 到 42px 圆标。白色实心 = 问题编号，蓝色实心 = 当前阶段，描边 = 后面的阶段。
- 图标方块：52 到 56px，描边中性；解法图标蓝色实底白图标。
- 胶囊：20 到 23px 字，999px 圆角。
- 两列之间的箭头：中性灰 → 图标，不用黄色贝塞尔箭头。
- 字号下限：正文 20px，说明句 19px，图里的小图标签 15px 起。灰色说明句尽量不写，要写也用白字。
