## 铁律详解

### 1. OOS 开封预算制
锁箱的价值 = 开封次数的稀缺性。预算（默认 ≤3 轮）在研究启动时宣布；
每次开封强制写 append-only 审计文件（`results/oos_unlock_audit.log`，写失败 raise）；
候选必须先过 TRAIN 全套（红线+扰动+子集+fold）才有资格消耗开封；
最后一轮留给部署决策。锁箱在本战役杀掉两个样本内极优候选（maxn 在 fold 层、
p0.5 在 OOS 层）——没有预算制，研究者会把 OOS 调成训练集。

### 2. 反向假设抢救
执行 agent 的假设被证伪时，会连带弃置数据里的反向信号。规则：任何 |t|≥3 的
截面信号，无论假设方向对错，必须自动补测反号并走完整判定协议。
战例：W8 agent 因"新币动量"假设失败写下 discard_no_signal，
但 freshness 的 IC t=-7.13 意味着反号（做空新币）是全场最强原始信号。
（它最终死于 fold 泛化，但那是完全不同的死因——判定路径必须走完。）

### 3. 两级死刑庭（信号真实 ≠ 结构可用）
- 一审（信号庭）：增量 IC——控现有因子后的残差 IC |t|≥2 + 两半期同号。
  判"是否携带新信息"。age（t≈6）、tvv（t=-3.48）都过了一审。
- 二审（结构庭）：跨币 fold——gen_ratio>0.3 且 test_worst_cagr≥0 + 11-seed 子集。
  判"换一批币还成立吗"。age（0.062）、maxn（0.11）死于二审；tvv 过。
两庭独立、顺序执行、都过才可 blend 进冠军候选。

### 4. 评估器完整性（假 0% 陷阱）
top_n+bottom_n ≥ 折内可选池大小时，引擎 `len(scores) < top_n+bottom_n` 跳过交易
→ CAGR 恰好 0%，读起来像"策略失效"。fold/子集评估必须按池比例缩放选币数
（`_scale_breadth`）。通用形式：任何"恰好为 0 / 多配置恰好相同"的评估读数，
先怀疑评估器再怀疑策略。

### 5. 波次脚本 __main__ 守卫
wave 脚本的网格执行代码若在模块层，任何 `from wave2 import apply_short_filters`
都会重跑整个网格（浪费算力 + results.tsv 重复行）。本战役踩了两次（wave2、wave6）。
规则：可复用函数在模块层，一切执行体在 `if __name__ == "__main__"` 内。

### 6. 模型分工
- sonnet 级：侦查/波次实现与执行/文献扫描/数据管线（本战役 ~20 个 agent）
- 主模型：对抗核查/设计判定/OOS 开封/收敛判定
实测：质量无损、token 省 ~60%。核查层多次拦截低层假阳性
（MAX 效应文献符号误读、残差动量引证错配、"15小时监控空窗"夸大 24 倍）——
**核查层不可省，且必须用最强模型**。

### 7. 数据解锁协议（forward-bet 制度化）
收敛后的正确出口不是"放弃"也不是"继续磨"，而是向用户提交付费资源清单：
每项标注【解锁的信号类 × 文献/侦察支持 × 成本量级 × 工程量 × 预期置信度】，
由用户拍板注资。本战役菜单：OI/清算流数据（Coinglass 类 API）、
tick/订单簿历史（Tardis 类）、链上数据、ML 序列模型管线。

### 8. 幸存者偏差可修复模式
交易所 meta API 往往永久保留下架资产（HL: isDelisted 标志 + index 稳定性），
且 candleSnapshot/fundingHistory 对下架币照常返回。宣布"下架币数据不可得"前
必查这条路。战例：55 个 HL 下架币全部恢复终止日期，纳入回测至终止日+强平，
同时修复反向的 tradability look-ahead（Binance 继续交易 HL 已下架币）。

### 9. 黑天鹅套件门禁
解析破产界（单腿 1/w）系统性乐观——组合联动（多空腿同日受损+费用+滑点）使真实
破产点显著更早（实测 +100~150% vs 理论 +182%）。里程碑门禁必须实跑注入式套件：
单币轧空（close/wick 变体×强度阶梯）、相关性崩盘（regime 滞后按引擎原生时序）、
连续瀑布、停机+崩盘、funding 尖峰、历史最坏日 wick 复检。
注入必须打在决策日+1（引擎 positions.shift(1) 计价语义）。
判据用相对同参数无冲击基线的【增量回撤】，避免无关历史回撤污染。

### 10. 宽宇宙的死法目录（供后续研究直接引用）
- 多头簿死法：相关性闪崩日山寨 -20~40%（majors 只 -10~15%），固定名义杠杆
  不适应持仓篮子波动率 → wick_backstop。对策：降杠杆/提高 ADV 门槛（结构性
  对策 vol-target 与市场状态 regime 均被证伪）。
- 空头簿死法：下架/轧空尾部（ORDI +148% close/+183% wick、JELLY 类）。
  对策：空头簿流动性下限（ADV≥$100M 甜点）——唯一同时改善收益与回撤的机制。
- 选币数与池大小：n_long+n_short 逼近池子 → 无选择 alpha（n28/池67 崩塌）。

  "IC 显著、组合不赚钱"的解剖样本：树打分排序不稳→换手爆炸→成本吞噬
  （EMA 平滑可修换手但修不了跨币集中）。
- W19 误杀-翻案链：临时加严门槛杀掉全场唯一"整片参数面存活"的候选，

- 杠杆天花板 3.5x 由合成冲击标定（历史回测完全不可见），安全上限 3.25x。
- 评估器守卫（_scale_breadth）键存在缺陷污染了三个波次引用的冠军子集基准，
  但因候选/冠军同协议对比，相对判决全部无需翻案——绝对基准重锚即可。
