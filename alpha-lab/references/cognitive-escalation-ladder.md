# 认知升级阶梯 — 对抗式研究方法论（完整参考）

> **撞墙 → 升级认知 → 继续** 的正向循环。
> 本文件是 SKILL.md「🔴 认知升级阶梯」章节的完整版：原始方法论 + 本-session 实证案例 + rigor 套件详解。
> 来源：crypto-deep-learning-beta 研究 session（2026-05~06）。可部署收益沿阶梯一路抬升：
> **148% → 386% → 476% → ~942% CAGR @ 40% DD**——正是因为搜索 4 次拒绝接受"完成"。

---

## 0. 核心命题：认知决定上限

「认知决定上限」是一套**具体方法**，不是口号。

当你撞到"搜索穷尽 / 不可能 / 没 alpha 了"这堵墙时——**那不是停止信号，而是触发信号**：
触发你沿一条**逐级不同视角的对抗式审查阶梯**往上爬。

三条铁律：

1. 每爬一级，要么挖出**全新的地**，要么以**结构性证据**确认一堵墙——绝不空手而归。
2. 永远不要"停下来问能不能放弃"。撞墙是工作的开始，不是结束。
3. 永远不要编造。是 **rigor 让幸存者可信**——没有 rigor 的高收益是负债，不是资产。

**🧠 认知的高度决定我们能达到的最终高度。** 这是本方法论的灵魂：
局部最优让人"束手无策"，但局部最优 ≠ 全局最优——卡住时，问题几乎从不在"没有更优解"，
而在"我的认知还没升到能看见它的高度"。爬这把阶梯 = 自我认知升级 = 从局部最优通往全局最优的唯一桥梁。

**本 session 实证**：可部署收益 148% → 386% → 476% → ~942% CAGR@40%DD，
正是因为搜索 4 次拒绝接受"完成"——其中 2 次（第 3 级完备性批判、第 4 级魔鬼代言人）真的挖出了价值，
另 2 次以结构性证据确认了墙（见 §2 收敛）。

## 1. 阶梯：每次撞墙爬一级

四级**从外到内、从具体到根本**。撞墙时从第 1 级开始，逐级往上，不要跳级——
每一级是一个**真正不同的视角**，不是把同一个搜索跑得更狠。

### 第 1 级：向外求 scout（别闭门造车）

**没思路时的第一反应是联网搜索，不是闭门空想。** 搜 2024-26 的论文 + 新数据类 + 前沿技术；
研究室外面的世界一直在产出新 lever 和新墙。具体去哪搜：

- **arXiv / papers-with-code / SSRN**：最新因子、风险溢价、择时、组合方法。
- **GitHub**：trending、factor-mining、量化开源仓库——前沿成果常常先开源再发论文。
- **🔴 非金融 AI 前沿（最容易被忽略、回报最高）**：RL / ML / DL / 自监督 / 序列模型 / 新架构
  （NeurIPS / ICML / ICLR）。很多 quant 突破是把游戏 / 机器人 / NLP 里的 RL/ML 技术**跨域迁移**过来的——别只盯金融圈。
- **新数据类**：链上、衍生品、社媒、另类数据——data 维度的新地往往比 model 维度更肥。

- **正面产出**：从文献找到全新的、结构正交的 lever。
  - 本 session：从文献找到 **VRP / 方差风险溢价**——一个和现有 taker 因子结构正交的新 lever。
- **负面产出（同样宝贵）**：从文献拿到"哪里不要再挖"的墙。
  - 本 session：Brigida 2026「市场 + 规模 + 动量已张成加密横截面」——这堵墙告诉你横截面因子空间已被张满，
    再去挖第 4 个横截面因子是浪费。**知道墙在哪，省下的时间就是挖到的价值。**

### 第 2 级：结构性 "why" / 衰减分类（要原因，不要"它没用"）

一个 lever 失败时，**必须拿到结构性原因**，而不是记一句"它没用"。
结构性原因能磨清 **EV 不在哪**，把整片不毛之地从地图上划掉，而不是一个点一个点试。

本 session 的三个结构性 why：

- **vol-timing 反预测**：因为**波动聚集**（volatility clustering）——高隐含波动 ⇒ 高已实现波动，
  所以"高波动时减仓"其实是在反向择时。这不是参数没调好，是机制本身反了。
- **flow / positioning 重编码会坍缩**：进 **taker 因子空间**——它和已有的 taker 因子线性相关，
  换个名字的同一个东西，加进来不增加自由度。
- **横截面因子已被张成**（呼应第 1 级 Brigida 墙）：市场/规模/动量已张满横截面，新横截面因子是这个子空间的线性组合。

> 心法：失败的 lever 不删了就算。问"它**为什么**失败"，答案往往直接划掉一大片你本来还想试的方向。

### 第 3 级：对抗式完备性批判（回溯）—— "搜索漏了什么？"

不是想新方向，而是**回头扫已有搜索的覆盖盲区**：未测过的仓库、未测过的数据、未加载的流。
对自己的搜索做对抗式审计："我以为我搜完了，但我**真的**每个角落都扫了吗？"

- 本 session：portfolio-stack 只测了 3 个 factor-mining 仓库里的 **1 个**——
  完备性批判一回溯就揪出了 **factor-mining-beta**（剩下 2 个里的价值）。
- 通用动作：列出你"声称已覆盖"的搜索空间，逐项找证据证明真的测过。
  没有证据 = 没测过 = 一块待挖的地。

### 第 4 级：对问题本身做魔鬼代言人（不是对因子空间）

最高一级，也是本 session **最好的结果**的来源。
前三级都在因子/lever 空间里找答案；第 4 级**跳出空间，挑战问题本身**：
目标对吗？结构对吗？那些被当成铁律的**"约束墙"本身**站得住吗？

- 本 session：杠杆实验**只测过"回撤减仓"一个方向**，从没测过**非对称的强势加仓**——
  利用冠军权益曲线 **+1.99 的右偏**，在强势时加杠杆而不是减。
  → **凸性 overlay（asymmetric convexity）**，**+89pp CAGR**，signal-shuffle **z = 2.94**。
  这是整个 session 单点收益最大的发现，藏在所有人默认"杠杆只能用来控风险"的约束墙背后。
- 通用动作：把每一条"我们一直这么做 / 这是约束 / 这不可能"写下来，逐条做魔鬼代言人。

> **盲点定律**：盲点藏在你**没看的地方**。凸性这个赢家就活在杠杆空间里原实验从没测的那一半。
> 永远问自己：**"我测的是两个方向 / 完整空间，还是只测了显而易见的那一半？"**

## 2. 为什么有效 / 何时停（收敛 ≠ 认输）

**为什么有效**：每一级是**真正不同的视角**——换的是问题，不是搜索的力度。
同一个搜索跑 10 遍还是同一个盲点；换个问题，盲点就暴露了。

**诚实的终点是「收敛」，不是「累了」**：

- 当**多个独立的对抗审查都确认同一堵墙**时，那才是真结论。
  - 本 session：**3 次独立审查三重确认**"现有数据下 2000% 不可达" → 这是 earned 的结论，
    据此把 2000% 定性为 **forward bet（前瞻下注）**，而不是过早放弃。
- **收敛前每一级仍在挖价值**：3 次审查在收敛之前，各自都还挖到了东西。
  收敛不是"什么都没找到所以放弃"，是"找了一圈，多个独立视角指向同一堵墙"。
- **收敛 ≠ 认输，是挣来的（earned）**。区别在于：认输是单一视角的疲劳；收敛是多个独立视角的一致。

判定"真收敛"的检查：

```
□ 至少 3 个【相互独立】的对抗视角，都指向同一堵墙？
  （独立 = 不同的问题/数据/方法，不是同一个搜索的 3 次重跑）
□ 每个视角在确认墙之前，是否都先尝试挖掘并给出了结构性证据？
□ 这堵墙是"现有数据/约束下不可达"，而不是"我懒得再想了"？
  → 如果是前者，明确写出"换什么数据/放松什么约束就能突破"（forward bet 的条件）
```

## 3. 让幸存者可信的 rigor 套件（绝不放松 —— funding-bug 教训）

阶梯负责**挖**，rigor 负责**验真**。两者缺一不可：
没有阶梯，你不够努力；没有 rigor，你的"高收益"是回测幻觉。
**杀掉一打幻觉的同一套 rigor，才是让你敢拿幸存者上真金白银的依据。**

| Rigor 检验 | 要求 | 防的是什么 |
|---|---|---|
| **SIGNAL-shuffle** | z > 2 | 随机化**哪些币 / 哪些时点带信号**（**不是** return-shuffle），打散信号-收益的对应关系后 alpha 应消失。z>2 说明 alpha 不是巧合。|
| **FAMILY-NULL** | P < 0.05 | 搜出来的东西**加冕前**先过 **best-of-N block-bootstrap**：在 N 次搜索的零假设分布下，这个冠军还显著吗？防多重检验 / best-of-N 幸存者偏差。|
| **SEAM-leak / open(t+1)** | 必须通过 | 择时信号要做**接缝泄漏检验**：用 **open(t+1)** 入场（信号在 t 收盘可见，t+1 开盘成交），杜绝用未来信息成交。|
| **TIME-SPLIT** | 两个半段都成立 | 回测期分前后两半，冠军在两段都要 work（呼应 Decay 检测）。|
| **CRASH-stress** | 必须通过 | 空头波动 / 高杠杆策略要过**崩盘压力测试**（极端行情下不爆）。|
| **LIQ-distance** | 安全边界足够 | 峰值杠杆要算**清算距离**：峰值 gross 杠杆离强平还有多少 headroom。|
| **基础假设** | 不可松动 | **funding ×1**（不打折）· **9bps** 费率 · **因果 .shift(1)**（所有信号滞后一期，杜绝 look-ahead）。|

> **funding-bug 教训**：曾经因为 funding 假设不诚实（打折/置零）跑出过虚高收益。
> 一旦在 baseline 里定下 funding ×1 / 9bps / .shift(1)，**整个研究过程不许改**。
> 改假设让数字变好看 = 投机取巧 = 成果作废（见 SKILL.md「禁止投机取巧」）。

## 5. 与现有 skill 章节的映射

这套方法论不是凭空新增，它**把 skill 里已有的几条原则升级成了一个可操作的循环**：

- **「永不言弃」「反自满条款」**（精神层）→ 认知升级阶梯给出了"不言弃时**具体怎么做**"的阶梯。
- **「Deep Dive 深挖」**（Innovation Backlog 补充）→ 是阶梯的一部分，主要落在第 3 级（完备性批判）。
  撞墙时优先按阶梯逐级爬，Deep Dive 是其中一环。
- **「跳出局部最优」机制 8（Level 1-4）**→ 和阶梯互补：机制 8 是在**因子/结构空间内**换方向，
  第 4 级魔鬼代言人则**跳出空间挑战问题本身**。
- **「终止条件 1：全局最优」+ 穷尽创新审计 7 问** → 新增**收敛判据**（多个独立对抗视角指向同一墙）
  作为"诚实终点"的硬标准，比"7 问全 yes"更强。
- **「机制 2 多重检验」「数据真实性铁律」** → rigor 套件（signal-shuffle / family-null / seam-leak …）
  是这两条的**具体执行配方**。

*要么挖到新地，要么以结构性证据确认墙；多副眼镜指向同一堵墙时才算真收敛。全程用 rigor 套件验真，绝不靠美化假设。*
