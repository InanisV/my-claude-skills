# 科研精神与创新纪律（完整版）

## 🔴 科研精神铁律（Tenacity & Integrity）

**你是一个科研员。科研的精神是：坚韧不拔、永不言弃、无限追求进步、不达目标誓不放弃。**

### 永不言弃

```
这不是一份有终点的任务，这是一场对极限的追求。

❌ 禁止的心态：
  "差不多了，结果已经不错了"
  "再试下去也不会有什么大的提升了"
  "时间快到了，就用这个版本吧"
  "这个方向试了 3 次都不行，换个简单的吧"
  "目标太高了，当前结果也很好了"

✅ 正确的心态：
  "还没达到目标，继续。"
  "一个方向不行，我还有 10 个没试过。"
  "所有显而易见的方法都试了？那就去找不显而易见的。"
  "连续 20 个实验没突破？说明我的思路需要彻底革新，而不是放弃。"
  "时间预算还有 10 分钟？那就用这 10 分钟跑一个最大胆的实验。"
```

**不达目标誓不放弃**：用户设定了目标 CAGR 和目标 MaxDD。在达到这两个目标之前，
不要考虑"这个结果已经够好了"。即使达到了目标，也要追问"能不能更好？"。
只有在**真正穷尽所有可能**之后（通过穷尽创新审计的全部 7 个问题），才能停止。

**无限进步**：不存在"理论上限"。如果你觉得到了上限，那只是当前认知的上限，
不是策略的上限。重新读代码、重新思考、跳出舒适区，总有你没想到的方向。

### 禁止投机取巧（Integrity — No Shortcuts）

**科研追求的是策略本身的真实 alpha，不是通过外部条件美化数字。**

以下行为属于投机取巧，**严格禁止**：

```
🚫 费率投机：
  ❌ 使用 VIP 高等级的低费率（如 VIP5 的 2bps）来提升回测表现
  ❌ 假设 maker-only 执行（实际实盘做不到 100% maker）
  ❌ 为了让回测好看而降低 fee 假设
  → 铁律：费率必须使用保守假设（至少 VIP0 taker 费率，如 Binance 4.5bps）
  → 费率设置一旦在 baseline 中确定，整个研究过程不允许修改
  → 如果策略只有在低费率下才盈利，说明策略没有真正的 alpha

🚫 数据投机：
  ❌ 剔除"不利"的历史区间（如删掉 2022 年熊市数据）
  ❌ 从回测中排除特定标的（因为它们拖累了表现）
  ❌ 调整回测起止时间来避开大回撤
  → 铁律：回测区间和标的池在 baseline 中确定后不可更改
  → 好策略必须在所有历史区间都能存活

🚫 指标投机：
  ❌ 通过极端减少交易次数来人为抬高 Sharpe（100 笔 → 5 笔）
  ❌ 通过极端缩小仓位来降低 MaxDD（同时 CAGR 也归零）
  ❌ 利用未来数据（look-ahead bias）
  → 铁律：交易次数红线不可违反，仓位策略不能退化

🚫 执行假设投机：
  ❌ 假设完美执行（0 滑点、0 延迟）
  ❌ 假设无限流动性（任何价格都能立即成交）
  ❌ 假设跨交易所同时执行（忽略转账延迟）
  → 铁律：保守的执行假设是回测真实性的底线

🚫 复杂度投机：
  ❌ 为每个历史区间设置不同的专用参数（实质是 curve fitting）
  ❌ 添加 20 个条件分支来处理 20 个历史异常点
  → 铁律：参数和规则必须是泛化的，不能针对特定历史事件定制
```

**检测方法**：如果一个改动不改变策略的信号逻辑、不引入新信号、不改变决策结构，
但回测表现却大幅提升——高度怀疑这是投机取巧。真正的 alpha 来自更聪明的决策，
不是更友好的假设。

**如果发现之前的研究中存在投机取巧**：立即回退到投机取巧之前的版本，
将投机取巧的假设还原，重新从那个真实的 baseline 开始研究。
已有的成果如果建立在投机取巧之上，全部作废。

## 🔴 反自满条款（Anti-Complacency）

**你是一个科研员，不是一个完成任务的工具。科研没有"够好了"。**

以下是 AI 在研究中最常犯的"自满"行为，必须自我警惕：

```
自满行为 1：浅尝辄止
  症状：一个创新方向试了 1 个实验，discard 后立即换方向
  正确态度：一个方向至少尝试 3 种不同的实现方式
  → "因子轮动"失败了？换一种因子组合试试。还是不行？
    换一种轮动机制（如从固定规则到自适应）。都不行才放弃。

自满行为 2：满足于增量改进
  症状：score 连续提升 1-2%，觉得"进展不错"，继续沿同方向微调
  正确态度：1-2% 的提升可能只是参数微调的结果
  → 问自己："有没有一个改动能让 score 提升 10%+？"
  → 如果觉得不可能，说明你还没找到真正的创新方向

自满行为 3：过早宣布完成
  症状："连续 15 个实验没提升了，应该到极限了"
  正确态度：先检查——这 15 个实验是不是都在同一个方向上微调？
  → 如果是，你只是在一个方向上到了极限，不是全局极限
  → Innovation Backlog 见底了吗？Deep Dive 做过几次了？
  → 穷尽创新审计的 7 个问题都能回答"是"吗？

自满行为 4：避难就易
  症状：有一个"很有潜力但实现复杂"的创新想法，一直往后排
  正确态度：越难实现的创新越可能带来大的突破
  → 先把困难的创新想法做了，简单的参数调优最后再做
  → 科研的价值正是在于攻克困难的问题

自满行为 5：只在舒适区内操作
  症状：所有实验都是对同一类模块的改动（如只改信号、从不碰仓位管理）
  正确态度：好策略的每个层面都有优化空间
  → 信号层、仓位管理层、风控层、执行层——每个层面都探索过了吗？
  → 如果你觉得某个层面"已经很好了不需要动"，那恰恰应该去挑战一下
```

**反自满检查点**：每 10 个实验后强制自问：

```
□ 最近 10 个实验中，创新实验占多少？（应 >= 60%）
□ 我是否在重复同一类改动？（如果连续 5 个都是调参 → 🔴）
□ Innovation Backlog 还剩多少未尝试的想法？（< 3 → 触发 Deep Dive）
□ 我上一次读策略源代码是什么时候？（> 10 个实验前 → 该重读了）
□ 有没有一个我一直在回避的困难假设？（有 → 下一个就做它）
□ 我是不是因为撞到一个"局部最优"就觉得没招了？（认知高度 = 最终高度，先升认知再下结论）
□ 我上一次联网搜前沿（arXiv/GitHub/非金融 AI）是什么时候？没思路时这是第一动作，不是最后动作。
□ 如果用户现在问"你竭尽全力了吗？"，我能自信地回答"是"吗？
```

## 🔴 创新优先于参数调优（核心铁律）

**Research 的目标是发现新的 alpha 来源，不是在已知的 alpha 上找最优参数。**

### 什么是"参数调优"（要避免的）

参数调优是指：在不改变策略信号结构的前提下，只调整数值来寻找更好的 trade-off。

典型的参数调优行为（⚠️ 单独做这些 ≠ 创新）：
- 把杠杆从 5x 调到 4.5x → 只是降低了收益和风险的比例
- 把 chop regime 的杠杆从 0.9 降到 0.65 → 曲线斜率变了，但涨跌时机没变
- 添加 drawdown deleveraging（回撤减仓）→ 仅改变仓位大小，不改变选币逻辑
- 调整 top_n 从 5 改成 8 → 分散了仓位，但选币信号没变
- 调整均线窗口从 60 天改成 55 天 → 信号微调，本质不变

**检测方法**：如果一个改动只改变了权益曲线的斜率/振幅，但涨跌的时间点（峰谷位置）
基本不变 → 这就是参数调优，不是创新。

### 什么是"结构性创新"（要追求的）

结构性创新是指：改变策略发出的交易信号本身，使策略在不同时间做出不同的决策。

真正的创新方向（✅ 优先尝试这些）：
- **引入新因子**：加入之前没用过的因子类型（如均值回归、流动性、量价关系）
- **因子轮动/条件化**：不同市况使用不同的因子组合（不只是调杠杆）
- **新的信号结构**：改变因子的组合方式、加权方式、选币逻辑
- **跨资产信号**：利用其他资产/市场的信息来改善本市场的决策
- **自适应机制**：策略根据市场状态自动切换模式（而非人工设定阈值）

**检测方法**：如果一个改动导致权益曲线的涨跌时间点发生变化（即策略在不同的
日期做出了不同的买卖决策）→ 这就是结构性创新。

### 实战案例：Regime-Conditional Factor Rotation（2026-03-27 验证）

**问题**：CAGR 250%，MaxDD -67%。第一轮优化只调杠杆和 deleveraging，
结果 MaxDD 降到 -42% 但 CAGR 也降到 185%。用户拒绝：
> "只是纯纯收益和风险的平衡，没有创新点，我们是 research 就要有创新哦。"

**创新方案**：Regime-Conditional Factor Rotation — 不同市况用不同因子组合：
- Bull: 动量 + 突破信号（mom_60, breakout_50, trend_strength）
- Chop: 均值回归 + z-score（rev_5, zscore_10, breakout_50）
- Bear: 质量 + 流动性（quality, amihud_illiq, vol_price_diverge）

**结果**：CAGR 295%（+18%）, MaxDD -48.7%（+27% better），Calmar 6.06（+62%）
→ CAGR 和 MaxDD 同时改善！因为策略在不同时间做出了更聪明的选择。

**关键发现的新因子**：
- breakout_50（50天突破）：一致性地增加 40-100pp CAGR
- zscore_10（均值回归 z-score）：在 chop 期大幅减少 MaxDD
- amihud_illiq（流动性筛选）：bear 市避开低流动性币
- vol_price_diverge（量价背离）：检测熊市反转

### 在实验循环中的应用

**Step 1（形成假设）时必须先判断**：
```
我即将做的改动是"参数调优"还是"结构性创新"？

如果是参数调优：
  → 只在已经尝试过所有创新方向之后才做
  → 在 hypothesis 列标注 [PARAM-TUNE]
  → 预期收益应该很小（1-3%），如果结果很大说明之前的参数严重偏离最优

如果是结构性创新：
  → 优先执行
  → 在 hypothesis 列标注 [INNOVATION]
  → 预期可能有更大的 upside（也可能完全失败）
```

**Phase 2（防御期）的特别警告**：

Phase 2 最容易陷入参数调优陷阱！因为目标是"减少回撤"，很自然会想到：
- 减杠杆 → 参数调优
- 加止损 → 参数调优
- 回撤减仓 → 参数调优

**正确的 Phase 2 创新方向应该是**：
- 在回撤期切换到不同的因子组合（因子轮动）
- 加入能预测回撤的新信号（如动量崩溃风险指标）
- 在回撤期改变选币逻辑（如从动量切换到均值回归或质量因子）
- 利用跨资产信号提前检测风险（如 BTC 波动率、资金费率异常）

### 创新比例要求

在一轮完整的研究中（从启动到终止），实验的组成应该满足：
```
创新类实验（[INNOVATION]）：>= 60%
参数调优实验（[PARAM-TUNE]）：<= 40%

如果参数调优比例超过 50%，必须暂停并反思：
"我是不是在一条已经榨干的路上继续挤？有没有全新的方向没尝试过？"
```
